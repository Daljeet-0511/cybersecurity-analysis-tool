# Cybersecurity Analysis Tool

## Project Overview
This project is created to practice version control and issue tracking in cybersecurity. It focuses on managing code changes, testing basic firewall rules, and tracking security-related tasks using GitHub and Freshworks.

## Project Objectives
- Use GitHub for version control.
- Create and manage different branches.
- Develop a basic firewall validation script.
- Track project issues using Freshworks.
- Use pull requests to review changes.

## Branch Structure
- **main:** Main production branch.
- **development:** Branch for ongoing development.
- **feature/firewall-configuration:** Branch for the firewall validation feature.

## Tools Used
- GitHub
- Git
- Python
- Freshworks

## How to Use
1. Clone the repository.
2. Create or switch to a feature branch.
3. Make changes to the project files.
4. Commit and push the changes.
5. Create a pull request to merge changes into the development branch.

## Purpose
The purpose of this project is to understand how cybersecurity analysts manage project files, document changes, and track security issues in a professional environment.
